Before/after vehicle screenshots for PR #344.

Image-only branch, deliberately not merged: it exists so the PR can show
pictures without adding a megabyte of JPEGs to the source history.

Both sets were captured by the SAME harness (`tools/vehshots.mjs` at the head of
`auto-vehicles`), the "before" set run against a worktree at `92d3637` -- the
commit the branch starts from. Framing, camera distance and lighting are
identical between the two; each vehicle is framed by its own length so size is
normalised and the comparison is of craftsmanship rather than of scale.
